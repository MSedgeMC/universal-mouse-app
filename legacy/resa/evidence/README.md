# Historical protocol fixtures

These support JSON files retain captured field mappings and hashes from Resa's research. `linux-discovery.json` is a cached test fixture, not a live scan. Inputs named by these records are not bundled.

The public repository excludes live GM320 configuration dumps, private backups, screenshots, logs, vendor executables and raw recordings. See the [source baseline notes](../../../docs/SOURCE_BASELINE.md) and [protocol documentation](../PROTOCOL.md) for provenance and limits.

Stored values, correlations and emulated tests do not prove physical effects or reconnect persistence.
